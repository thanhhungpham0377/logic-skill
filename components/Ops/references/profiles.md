# Stewardship profiles

| Profile | Purpose |
|---|---|
| `local` | Repository hygiene, metadata, documentation, and basic attribution |
| `public` | Public-release, history, privacy, asset, and open-source readiness |
| `handoff` | Ownership, environment inventory, runbook, rollback, and transfer readiness |
| `maintained` | Stale branches/issues, documentation drift, lifecycle and maintenance signals |

Findings must be reported as `pass`, `fail`, `warning`, `not-applicable`, `not-verified`, `manual-review`, or `suppressed`.
